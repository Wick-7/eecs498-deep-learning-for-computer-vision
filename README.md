# EECS 498/598: Deep Learning for Computer Vision

My completed assignments for the University of Michigan's [Deep Learning for Computer Vision](https://web.eecs.umich.edu/~justincj/teaching/eecs498/WI2022/) course. The notebooks and helper code include course-provided starter materials alongside my implementations.

| Assignment | Topics |
| --- | --- |
| A1 | PyTorch basics and k-nearest neighbors |
| A2 | Linear classifiers and two-layer networks |
| A3 | Fully connected and convolutional networks |
| A4 | One-stage and two-stage object detection |
| A5 | Image captioning, RNNs, LSTMs, and transformers |
| A6 | VAEs, GANs, network visualization, and style transfer |

The notebooks were developed with PyTorch and Google Colab. Saved model checkpoints and example results are included. The downloaded Pascal VOC dataset used in A4 is excluded from this repository; place it in `A4/VOCdevkit/` to run the object detection notebooks.

This repository is a record of my coursework. Credit for the assignment prompts and starter code belongs to the University of Michigan course staff.
